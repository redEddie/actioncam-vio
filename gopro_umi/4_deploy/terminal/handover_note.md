# 로컬 컴퓨터 (배포 환경) 제미나이(Gemini) 인수인계서

이 문서는 서버에서 SmolVLA 모델 학습을 마치고, 로컬 컴퓨터(GTX 1060)에서 실제 로봇(SO-100/SO-101)을 구동하기 위한 핵심 인수인계 사항입니다.

## 1. 커스텀 IK 솔버 (역기구학) 적용 사항
로컬 컴퓨터에 이미 완성된 IK 솔버가 있으나, 아래 핵심 원리가 반영되어 있는지 확인하고 추론(Inference) 코드에 연동해야 합니다.
*   **Yaw 제약 해제 (핵심)**: 5-DoF 로봇의 구조적 한계로 인해, 직진(X축) 이동 시 Z축 출렁임이나 아치형 궤적이 발생합니다. 이를 해결하기 위해 IK 계산 시 `ee.wz` (Yaw, Z축 회전)의 제약을 완전히 해제(자유화)하고, `ee.wx`(Roll), `ee.wy`(Pitch)만 수평으로 고정하여 손끝이 숙여지지 않게 유지합니다.
*   **연속성 보장**: IK 계산 시 이전 관절 각도를 Initial Guess로 사용하여 관절이 갑자기 튀는 현상을 막아야 합니다.
*   **그리퍼 매핑**: 모델의 Action 결과(0.0~1.0)를 실제 모터 값(3300 닫힘 ~ 500 열림)으로 변환하는 함수가 필요합니다.

## 2. SmolVLA 모델 학습 데이터 (IMU 미포함)
이번 SmolVLA 모델은 **IMU 센서값이나 관절 모터 각도를 전혀 사용하지 않고 학습**되었습니다. 
*   **입력(Observation)**: 고프로 카메라 224x224 RGB 영상 (`images.top`), 현재 손끝의 7D 좌표 (`state`: X, Y, Z, Rx, Ry, Rz, Gripper)
*   **출력(Action)**: 다음 목표 손끝의 7D 좌표

따라서 로컬 컴퓨터에서 추론 스크립트를 작성할 때, 복잡한 IMU 데이터를 파싱할 필요 없이 **카메라 영상**과 **현재 손끝 좌표**만 모델에 넣어주면 됩니다.

## 3. 로컬 컴퓨터 추론(Inference) 파이프라인
로컬 제미나이는 다음 흐름에 따라 `deploy_smolvla.py` (또는 추론 스크립트)를 작성해야 합니다.
1.  **모델 로드**: `smolvla_run/checkpoints/020000/pretrained_model` 폴더에서 모델과 가중치를 로드합니다.
2.  **관측(Observation)**: 웹캠(고프로) 영상 1장을 가져오고, 현재 로봇의 모터 상태를 FK(정기구학)로 계산하여 현재 손끝의 7D 좌표를 구합니다.
3.  **추론(Inference)**: 영상과 7D 좌표를 모델에 넣고 다음 목표 7D 좌표(Action)를 반환받습니다.
4.  **제어(Control)**: 반환된 목표 7D 좌표를 로컬 IK 솔버에 넣어 관절 각도로 변환한 뒤 로봇 모터로 전송합니다.
